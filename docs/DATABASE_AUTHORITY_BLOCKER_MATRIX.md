# Database authority blocker matrix

Project Version: 0.2.0-dev.7

Decision: **NO-GO for secure persistent multiplayer dogs under the required automatic lifecycle contract.** Offline feasibility is useful but does not resolve the missing native authority boundaries. Each D gate uses the requested classification; runtime absence is stated separately.

| Gate | Classification | Evidence achieved | Remaining blocker / next sufficient evidence |
| --- | --- | --- | --- |
| D1 authenticated identity | BLOCKED | Connection-resolved callback player; identified client-only helper and numeric precision hazard | Lossless server connection-derived principal string plus current slot/episode/session, forged/stale/missing actor refusals in two-client tests |
| D2 native lifecycle | BLOCKED | Existing complete bounded trace rechecked against packaged hashes; removal/exclusion candidates characterized | Authentic origin/reconciliation or complete save exclusion/withdrawal, all supported representations, no copied/stale body adoption or duplicate replacement |
| D3 sole movement producer | BLOCKED | Native path/follow/block candidates inspected | Verified sole producer/arbitration with vanilla needs/emergencies, cancellation, unload, disconnect, obstacles and multiple observers |
| D4 physical interactions | EXPERIMENTAL | Vanilla feed/pet/attachment completion candidates and duplicate/no-op hazards identified | Trusted actual consumption/acceptance/resource/equipment receipts, cancellation/replay/commit recovery. No runtime proof |
| D5 private transaction contract | FEASIBLE | Test-only world aggregate, owner/index/relationship/receipt candidate, revision checks and replay tested offline | Full schema/capacity/retention, real principal/binding integration, production migration and durable/native commit remain unresolved |
| D6 crash/rollback behavior | EXPERIMENTAL | Fault injection, ambiguous/corrupt/pending slot refusal, private rollback and combined rollback limit tested offline | Actual process/power/storage ordering; no fsync/atomic promotion/native seal. Paired rollback needs independent freshness source or explicit accepted semantics |
| D7 singleplayer runtime | NOT TESTED | No PZ launched, deployed or modified | Known-clean effective environment, reviewed isolated proof and separately authorized disposable runtime execution |
| D8 two-client dedicated runtime | BLOCKED | No dedicated server/client launched or remote state changed | D1–D6 sufficient safe interfaces plus authenticated two-client adversarial/restart/transport evidence |

Five historical loose-class failures and two additional packaged/loose differences are environmental evidence, not failures repaired by this proof. [Drift report](NATIVE_OVERRIDE_DRIFT_REPORT.md). No gate is runtime PASS. D5 FEASIBLE is restricted to the synthetic logical subset, not the full production canine database.

Permanent identity/history remain private and independent of physical absence. Natural primary bond 100, separate secondary bonds, one finite session handler lease, SelfCare default and disabled StoreOffline remain design contracts. No gameplay permissions, task execution, training, care AI, pack, model/animation or growth are implemented in this revision.

This D1–D8 table does not replace project release gates: **G6 NOT TESTED; G7 BLOCKED / NOT TESTED; stable-release G8 BLOCKED.** Public backup/CI and test count do not imply runtime readiness.
