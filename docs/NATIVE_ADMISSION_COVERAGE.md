## What the nine hooks actually establish

[NATIVE_ADMISSION_GUARD.md](NATIVE_ADMISSION_GUARD.md) preserves the earlier selected-hook report. Installation validates the complete action class/new/complete/index/metatable/native API set, reserves once and latches drift. Wrapper lookup cannot intercept a Java-to-Java call. Notifications after world insertion cannot retroactively make an unauthorized admission safe. The new [central policy](SERVER_ADMISSION_GUARD.md) standardizes refusal decisions at project boundaries; it does not add native hooks.

Native spawn definitions with no next stage, mating or hutch target reduce ordinary reachability. Existing serialized items/vehicles/hutches, forced drops, generic factories, worker re-entry and previous-session taint remain separate obligations. **No supported physical lifecycle is certified for multiplayer ownership.**
