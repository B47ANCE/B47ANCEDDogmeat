# Animal lifecycle support matrix

Project Version: 0.2.0-dev.12

“Diagnostic” means an offline-tested observation/refusal implementation. It is not native gameplay support. Every physical continuity claim below remains BLOCKED or NOT TESTED. C references link to [native coverage](NATIVE_ADMISSION_COVERAGE.md); `P` is the retained private canonical record. Native markers never authorize it.

| Lifecycle | Native behavior/evidence | Current project behavior | Support / required acceptance |
| --- | --- | --- | --- |
| First disposable world | C01 constructor; native outcome can be uncertain | Explicit authorized receipt-first single attempt; no auto-init/retry | Diagnostic implemented offline; actual SP/dedicated NOT TESTED |
| Ordinary save/load | C02 serializes body/N/M | Exact loaded checkpoint/private slot; matching body QUARANTINE | BLOCKED: provenance and native/private durability |
| Full server restart | New references/process latch | Recover P independently; no ADMIT even exact replay | BLOCKED: previous-session integrity and two-client restart |
| Disconnect/reconnect | Online/simulator relationships may change | Neither reconnect nor new online ID transfers private ownership | BLOCKED: actual authenticated actor/episode and native binding |
| Chunk unload | C03 native virtualization | Same known handle can become DETACHED_PENDING/DEFER; P retained | Diagnostic only; missing is never dead/respawn |
| Chunk reload | C03 reference or reconstructed body, stats catch-up | Same handle exact match still Q; unexplained replacement conflicts | BLOCKED: exclusive native return and catch-up/growth behavior |
| Carry/pickup | C05 removes live representation | Selected managed completion refused | Unsupported; private physical transaction not implemented |
| Inventory release | C04/C06/C07 reconstruction/copy | Selected drops refused; policy REJECTs managed route | BLOCKED: parser/forced drop upstream coverage |
| Trailer add/remove | C08 reconstructs and copies native/public fields | Both managed completions refused | Unsupported; interruption/list membership not enough |
| Vehicle/hutch restore | C09/C10 direct load/release | No authorized private rebind; policy REJECT | BLOCKED: native pre-admission and transfer receipts |
| Growth/maturation | C11 replaces world/inventory/trailer body | No gameplay; no successor stage in test definition; policy REJECT | BLOCKED: private identity/history/equipment transfer and interruption |
| Death | C12 postfact death notification; corpse can carry M | Current-session known-dead refusal; P retained | BLOCKED: durable terminal transaction/tombstone |
| Recovery/reanimation | C12 new body/native integer | No automatic replacement, revival or re-association | Unsupported; explicit recovery design required |
| New spawn/birth/population | C13–C16 generic/native origins | Type or copied marker never allocates P | BLOCKED: controlled genesis and natural catalog closure |
| Forged/duplicate marker | C19 public update | Q for indistinguishable exact replay; REJECT for detected conflict | Refusal tested offline; preventive native coverage unproved |
| World/private rollback | Exact matching old pair may recover P | Physical body still Q; partial mismatch preserves data and recovers nothing | BLOCKED: independent freshness/rollback evidence |
| Ownership/privileged actions | C21 server boundary | Current policy noADMIT plus independent dedicated Session fence | Disabled until all declared supported lifecycle/authority/runtime gates pass |
| Unmanaged vanilla animal | Native behavior retained by validated wrapper delegation | Excluded from managed census counts; no global constructor patch | Delegation tested offline; SP/dedicated compatibility NOT TESTED |

No advanced obedience, veterinary, doghouse gameplay, inventory/equipment system or original model work is included. Future roadmap and acceptance meanings remain intact. [GROWTH_IDENTITY_FEASIBILITY.md](GROWTH_IDENTITY_FEASIBILITY.md) preserves the doghouse growth design without treating current restrictions as scope removal.
