# B47ANCE'd Dogmeat - Persistence Test

## Overview

MP testing build - dedicated multiplayer NOT TESTED

Version 0.2.0-dev.11 is an experimental development diagnostic for native animal save/load research. It is not a playable dog companion release. Use a new disposable world only.

## Features

- Default-off persistence test mode with an administrator confirmation workflow.
- Temporary vanilla raccoon carrier for native lifecycle and save/load investigation.
- Guarded server-side diagnostic requests and private persistence foundations.
- Independent German Shepherd native type group: original coat plus variations 1 and 2, sharing the raccoon animation skeleton. Vanilla raccoons remain available.
- Revised Shepherd skinning with independent head turns and more open rest/death hindlegs, with optional tail height reflecting native health; offline candidate, actual game behavior untested.
- Custom transparent German Shepherd mod icon and unchanged project thumbnail.

## Compatibility & Requirements

Targets Project Zomboid Build 42.21. Lua-only runtime; no custom Java, JAR, native module or other mod dependency. Offline Lua tests pass; actual single-player and dedicated multiplayer behavior is NOT TESTED. Requires a pristine vanilla installation for testing. Modified native classes, Java agents and third-party loaders are unsupported.

## Configuration

Persistence Test Mode defaults to disabled. Enable it only in a new disposable world for controlled administrator testing. Never provision against an established gameplay save. Disabling it refuses diagnostic requests; it does not certify or migrate existing animal identity.

Tail Health Indicator defaults to enabled. It reads native health for Shepherd presentation only; disabling returns a neutral tail. It does not enable ownership, tasks or a custom health system.

## Known Issues

- Multiplayer ownership, authenticated identity continuity and live task control remain disabled.
- Native admission coverage and restart continuity are unproven. Copied animal markers never authorize ownership.
- Shepherd geometry/UVs are preserved. The revised skin and motion form a candidate awaiting visual and game review; actual game import, movement/contact and remote health presentation remain NOT TESTED. Each mesh has 2.59 million triangles; performance is NOT TESTED.
- Shepherds inherit raccoon autonomy and sounds; no companion behavior, automatic world population, breeding or fence climbing. Corpses temporarily use the same whole-body model.
- The raccoon remains the separate persistence diagnostic carrier.
- Do not use valuable saves. No production migration or recovery guarantee is provided.
