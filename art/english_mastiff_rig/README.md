# English Mastiff rig experiment — stopped

Tested Project Version: 0.2.0-dev.7

On 2026-10-16 the user directed regeneration if an open mouth is needed. Rigging
on the closed-mouth source is stopped. Barking, panting, eating, drinking and
retrieval require usable oral geometry; the source has no modeled oral cavity,
tongue or teeth. Do not adopt this experiment as an approved animation asset.

The original em-v001 checkpoint in ../english_mastiff remains unchanged and is
backed up at ca3d53a36ff423f632fbfd34eaa907b674f37f4b. This directory retains
the interrupted local rig, scripts, draft clips and reports for recovery.
Some reports describe earlier work-in-progress outputs and are stale against
the latest exports. There is no final artifact manifest or acceptance PASS.

The experiment created an original 42-bone intermediate armature and 37
procedural clip foundations, with 19 authoring attachment specifications.
Bone-heat skinning, underside/tail isolation and plantar corrections were
explored. Deep sit/lie deformation remains provisional; the set is not a
finished natural canine animation library. Earlier structural checks and loop
seams do not prove deformation quality or current export integrity.

The local bone hierarchy is not a native bind-pose match. Installed native
inspection is in validation/native_audit.json: 35 raccoon frames, 25 weighted
names, 13 native clips and 19 XML nodes; native loader/shader observations
remain source evidence only. No native mesh, bind matrices or clips were copied.

No additional Meshy credits were spent. No game/server was launched, mod
installed, gameplay/saves changed or Workshop upload performed. The raccoon
remains the active test carrier; ownership and live task control stay disabled.
